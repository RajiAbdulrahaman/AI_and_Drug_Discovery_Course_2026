# Short description of the data curation workflow: The workflow demonstrates a standard QSAR data curation pipeline using ChEMBL bioactivity data. Firstly, Google Drive was mounted in Google Colab to enable persistent data storage. Required libraries, including chembl_webresource_client and pandas, are installed and imported. The target protein (RAD51) was identified by querying the ChEMBL target database, and the corresponding ChEMBL target ID was selected. Bioactivity records associated with this target are then retrieved, filtering specifically for IC₅₀ measurements. The raw bioactivity data are converted into a pandas DataFrame and saved as a CSV file. Data curation steps follow, including removal of missing IC₅₀ values, selection of relevant fields (molecule ID, SMILES, IC₅₀), and classification of compounds into active, intermediate, or inactive classes based on IC₅₀ thresholds. Compounds lacking valid SMILES strings are excluded. Finally, a cleaned and preprocessed bioactivity dataset suitable for downstream QSAR modeling is generated and saved.
